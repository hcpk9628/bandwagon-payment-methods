## 关于自动扣款的真相

这是搬瓦工官方知识库里写得非常直白的一条：他们**从不自动扣款**，包括信用卡和 PayPal 在内的所有支付方式都不会被自动划款。原因是技术上做不到——官方不存储客户的支付信息，所以根本无法发起自动扣费。所有付款都是用户主动发起的，没有例外。

对比那些到期默默从卡里划走年费的 VPS 服务商，这个设定对健忘症患者其实很友好：最坏的结果是忘续费导致服务暂停，而不是账户被多扣一笔钱。

不过系统仍会做提醒类的事情：除非你手动关闭续费，到期前 7 天会自动生成新账单。如果账户里有余额，余额会自动抵扣账单；余额不够，官方会通知你，并给出 7 天的付款宽限期，逾期未付服务会被暂停。

所以这里有个选择题：**怕忘续费的人，与其依赖信用卡代扣（它也没有），不如在后台预存账户余额**。官方明确支持这种做法，充进去的钱会在未来账单生成时自动抵扣，效果等同于自动续费，但钱的控制权始终在你手里。后台还有 Renewal 开关，设为 OFF 的话，到期后 VPS 会被自动终止且不再发账单，适合确定不用了的情况。

## 续费与退款规则

退款方面，官方 FAQ 写明提供 **30 天退款保证**，但受服务条款约束，不是无条件的。几个关键点：

- 退款需要在后台提交申请，由账单部门处理；
- 按照服务条款，退款只按**原支付方式退回**——用支付宝付的就退回支付宝，用 PayPal 付的就退回 PayPal；
- 条款里明确把 IP 地址相关的付款列在退款范围之外，这类附加费用要留意；
- 第三方 FAQ 的补充说法也一致：退款针对新订单、需要在 30 天内提出，过期就只剩续费或不续费的选择。

顺带说一句计费周期的灵活性：后台支持更改账单周期，如果你买了月付套餐后来觉得年付更划算，不用退单重买，改个周期就行。结合前面说的余额预存机制，长期用的话年付加余额自动抵扣是最省心的组合。

支付宝通道偶尔会抽风，这不算新闻。各教程给出的处理思路基本一致：不要在同一个通道反复重试，直接换一种支付方式，比如改用信用卡（Stripe 通道）或 PayPal 完成这次订单。银联通道可以作为备选。反复重试不仅解决不了问题，还可能触发支付渠道的风控。如果四种方式都失败，那就不是你的问题，去后台提交工单让账单部门查。
